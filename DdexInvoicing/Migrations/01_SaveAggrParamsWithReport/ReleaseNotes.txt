Вначале нужно выполнить скрипт Upgrade.sql из данного фолдера
Скрипт добавляет небходимые колонки к таблице DdexReport и заполняет их необходимыми значениями
на основе данных из таблиц AgreementParam и CcidExchangeRate
Также меняются хранимые процедуры для извлечения расчетных параметров из таблицы DdexReport,
а не AgreementParam, как было перед этим.
Кроме того, добавлена хранимая процедура удаления отчета, предназначенная для
нужд тестирования.
В интерфейсе пользователя выполнены следующие изменения.
При регистрации отчета проверяется наличие необходимых данных в AgreementParam,
после чего они копируются в DdexReport. После этого данные из AgreementParam для
зарегистрированного отчета не используются, берутся зарегистрированные значения в отчете
без дополнительного подтверждения.
Расчетные параметры из отчета можно увидеть на закладке Інформация формы отчета. Для этого
добавлена новая ппанель.
ЗАМЕЧАНИЕ: после данного измменения привязка параметров к договору по сути утратила смысл. Необходимые
значения можно было бы просто корректировать при регистрации отчета, используя по умолчанию значения из предыдущего
(в календарном смысле) отчета. Только для самого первого отчета информацию нужно было бы ввести с нуля.
